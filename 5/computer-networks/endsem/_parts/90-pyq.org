** How to use this bank

Attempt every question on paper before you look anything up. Time-box each
one at about one minute per mark and stop when the timer ends, even
mid-answer. Draw the diagrams, because the marks for them are separate
marks. Only then open the answers file, and log every topic you had to
guess.

*** Q1  Network performance metrics  [5]  [CO1]

What are the parameters for measuring performance of a network? Explain
each in detail.

HINT: Cover bandwidth, throughput, the delay terms, jitter and loss, and
give one way to measure each.

*** Q2  Two access networks  [5]  [CO1]

Explain any two access networks with diagram.

HINT: Pick two of DSL, cable, fibre to the home or enterprise access, and
trace the shared medium and the split between the access network and the
ISP.

*** Q3  HTTP proxy server  [5]  [CO2]

How does a http proxy server work? Explain in context with relevant http
fields.

HINT: Recall that a proxy is both a server and a client, and name the
request and response header fields that carry forwarding and freshness
information.

*** Q4  Cookies and state  [5]  [CO2]

An application developer wants the user name information to be passed
across all webpages that he/she browses across the website. Suggest a
mechanism to achieve this as HTTP is a stateless protocol.

HINT: Think of the cookie mechanism, meaning the response header that
plants the state and the request header that returns it.

*** Q5  Pipelining versus stop-and-wait  [5]  [CO3]

What is the advantage of pipelining protocols over stop and wait protocol?
Discuss in detail.

HINT: Compare link utilisation with one frame in flight against a window
of frames, using the stop-and-wait efficiency expression as the baseline.

*** Q6  NAT purpose  [5]  [CO4]

Discuss the purpose of using Network Address Translation (NAT). In which
networking component it is implemented and how it works?

HINT: Cover the private to public mapping, the translation table, and the
device that performs the rewriting.

*** Q7  RIP and OSPF  [5]  [CO4]

Network A is using RIP and Network B is using OSPF as their routing
protocols. All configurations required for communication between two
networks are perfect. Both networks are in same autonomous system. But
packets from both the network are failing to ping each other. What might
be the cause for this? Explain in detail.

HINT: Suspect the exchange of routing information between the two
protocols, such as redistribution, metric translation or area boundaries.

*** Q8  DHCP steps  [5]  [CO4]

Explain the steps in fetching an IP allocation for a host by using DHCP.

HINT: Walk the message exchange in order and say what each message

*** Q9  Ethernet frame  [5]  [CO5]

Draw Ethernet frame structure and explain all the fields in detail.

HINT: Draw the frame from preamble to frame check sequence and give the
size and purpose of every field.

*** Q10  Two-dimensional parity  [5]  [CO5]

With the help of an example explain two-dimensional parity. Why it is
preferred over single-dimensional parity?

HINT: Lay the data out as a grid, add row and column parity, and show
which error patterns the intersection of a failing row and column can
locate.

*** Q11  OSI layers and FTP  [10]  [CO1]

Explain the seven-layer architecture of computer network communication.

HINT: Give the seven layers with a one-line duty each, then walk one FTP

*** Q12  Application protocols  [10]  [CO2]

  i)   E Mail

  iii) Remote Access to any device

*** Q13  TCP versus UDP  [10]  [CO3]

*** Q14  Mobility routing  [10]  [CO4]

How a host handle a communication to an unknown host in the same LAN with
