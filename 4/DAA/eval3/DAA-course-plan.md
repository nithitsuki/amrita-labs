**Pre-Requisite(s):** Data Structures and Algorithms, Discrete
Mathematics 

 

**Course Objectives** 

 

This course aims to provide the fundamentals of algorithm design and
analysis, specifically in terms of algorithm design techniques,
application of these design techniques for real-world problem solving
and analysis of complexity and correctness of algorithms.  

 

**Course Outcomes** 

 

  -----------------------------------------------------------------------
  CO1    Evaluate the correctness and analyze complexity of
         algorithms.   
  ------ ----------------------------------------------------------------
  CO2    Implement various algorithmic design techniques and solve
         classical problems.

  CO3    Design solutions for real world problems by identifying,
         applying and implementing appropriate design techniques.

  CO4    Design solutions for real world problems by reducing to
         classical problems.

  CO5    Analyze the impact of various implementation choices on the
         algorithm complexity.

**List of Lab Programs**

1.  Time Complexity Analysis of Basic Algorithms

Write programs to analyze and compare the time complexity of algorithms
with O(1), O(n), O(n²), O(log n) and exponential behaviors using
iterative and/or recursive approaches for varying input sizes. Plot the
graph and observe.

2.  Performance Evaluation of Searching Algorithms

Implement Linear Search, and Binary Search (iterative and recursive), on
large datasets and compare their execution time and efficiency.

3.  Comparative Study of Sorting Algorithms

Implement and analyze Bubble Sort, Selection Sort, Insertion Sort, and
Quick Sort, and compare their best, average, and worst-case
complexities.

4.  Divide and Conquer Techniques

Solve Merge sort, and other real-time problems using the identified
approach.

5.  Greedy Algorithm -- Activity Selection and Knapsack

Implement Activity Selection Problem and Fractional Knapsack Problem
using greedy approach and analyze their optimality.

6.  Dynamic Programming -- Optimization Problems

Implement Fibonacci, and 0/1 Knapsack to demonstrate optimal
substructure and overlapping subproblems.

7.  String Matching Algorithms

Implement and compare Naïve String Matching, Knuth--Morris--Pratt (KMP),
and Rabin--Karp algorithms.

8.  Graph Representation and Traversal

Implement a graph using Adjacency Matrix and Adjacency List, and perform
Breadth First Search (BFS), Depth First Search (DFS), and cycle
detection.
