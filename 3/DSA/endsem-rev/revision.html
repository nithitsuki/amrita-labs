4.6. f) expression conversion (6 conversions)

Infix, Prefix, PostFix convertion to each other

4.6.1. Infix to postfix

  • add letters to output
  • kep pushing to stack until stack-top is of equal or higher precedence

if eq or higher precedence, keep popping it

  • if ’)’ pop until ’(’

4.6.2. postfix to Infix

  • push letters to string stack
  • if operator, push “(op2 + operator + op1)” eg: ab+. op1 = b, op2 = a, pushing (a+b)

4.6.3. Infix to prefix

reverse infix, convert to postfix, reverse again, done
